# 基于深度学习的足踝关节骨损辅助诊断算法实现步骤

> 根据论文《基于深度学习的足踝关节骨损辅助诊断研究》整理。
> 
> 本文档不是论文原文复刻，而是将论文中的算法内容改写为可落地的工程实现步骤，方便后续复现、编码、训练与部署。

---

## 1. 算法目标

论文整体目标是构建一个面向足踝关节 X 光片的辅助诊断系统，完成以下 3 类任务：

1. **过滤干扰样本**：区分完全粉碎型骨损与非完全粉碎型骨损。
2. **识别踝关节区域**：先把踝关节从整张 X 光片中定位出来。
3. **进行骨损识别与关节缝隙提取**：
   - 对小尺寸骨损进行目标检测；
   - 对踝关节缝隙进行语义分割，用于辅助判断肌肉/韧带损伤。

因此，完整系统可以拆成一个多阶段流水线：

```text
原始 X 光片
  ↓
阶段 1：骨损类型二分类（过滤完全粉碎型骨损）
  ↓
阶段 2：踝关节检测（裁剪 ROI）
  ↓
阶段 3A：小目标骨损检测
阶段 3B：踝关节缝隙语义分割
  ↓
输出：骨损框 + 缝隙掩膜 + 辅助诊断信息
```

## 4. 阶段 1：完全粉碎型 / 非完全粉碎型骨损分类

这一阶段的目标不是最终诊断，而是**过滤干扰数据**。

### 4.1 为什么要先做分类过滤

论文指出，完全粉碎型骨损：

- 骨骼物理结构离散性大；
- 对小目标检测与后续分割帮助不大；
- 会增加后续网络训练难度；
- 会影响系统整体稳定性。

因此先做一次二分类，可以让后续网络只处理非完全粉碎型骨损数据。

### 4.2 候选分类网络

论文对比了 3 个模型：

- VGG-16
- GoogleNet
- ResNet-50

建议工程上优先复现 **ResNet-50**，因为：

- 易于在 PyTorch 中直接实现；
- 后续检测阶段也用到 ResNet；
- 结构统一更方便维护。

### 4.3 输入预处理

实现步骤：

1. 读取原始 X 光图像。
2. 灰度图可转成 3 通道，便于使用标准 CNN 主干。
3. 将图像统一 resize 到 `1000 × 1000`。
4. 对训练集进行常规归一化。
5. 构建二分类标签。

### 4.4 模型训练参数

论文设置：

- 输入尺寸：`1000 × 1000`
- 框架：PyTorch
- 优化器：Adam
- 学习率：`0.0001`
- batch size：`5`
- epoch：`200`

### 4.5 损失函数

使用二元交叉熵：

\[
L = -(y \cdot \log(p) + (1-y)\cdot \log(1-p))
\]

其中：

- `p`：预测为正类概率
- `y=1`：非完全粉碎型骨损
- `y=0`：完全粉碎型骨损

### 4.6 训练步骤

1. 初始化分类网络。
2. 读取训练集与验证集。
3. 前向传播得到二分类概率。
4. 计算 BCE loss。
5. 反向传播，更新参数。
6. 每轮记录：
   - loss
   - accuracy
   - precision
   - recall
   - F1
   - AUC
7. 保存验证集指标最优模型。

### 4.7 推理输出

该阶段输出：

- `class = complete_comminuted / non_complete_comminuted`
- `score = probability`

当结果为“完全粉碎型骨损”时，可在完整系统中直接中止后续小目标检测流水线，或者单独进入一个专门处理严重骨损的分支。

## 5. 阶段 2：踝关节检测（Resnet-RPN）

这一阶段的任务是先把整张 X 光片里的踝关节检测出来，并裁剪为 ROI，供后续骨损检测和分割使用。

### 5.1 为什么先检测踝关节

因为论文数据中的骨损通常很小。

如果直接把整图缩放到固定尺寸：

- 小骨损会进一步缩小；
- 细节会丢失；
- 检测网络更容易漏检。

因此先检测踝关节并裁剪，可以显著提升小目标在输入中的相对比例。

### 5.2 网络来源

论文从 **Faster R-CNN** 出发，提出了简化版 **Resnet-RPN**。

Faster R-CNN 原结构：

1. Backbone CNN
2. RPN
3. ROI Pooling
4. 分类和回归头

论文改造思路：

- 本任务只关心“踝关节区域定位”；
- 不需要复杂的多分类头；
- 因此去掉 ROI Pooling 和后续分类回归头；
- 只保留 **ResNet-50 + RPN**。

### 5.3 Resnet-RPN 实现结构

建议按以下结构实现：

1. `backbone = ResNet50`
2. 从 backbone 的高层特征图取出输出特征
3. 在特征图上滑动生成 anchors
4. RPN 输出：
   - 前景/背景分类分数
   - 边界框回归参数
5. proposal 层根据预测结果生成候选框
6. 做 NMS，保留前景得分最高的框

### 5.4 Anchor 设置

论文中每个特征点使用：

- 3 种尺寸
- 3 种长宽比
- 共 9 个 anchor

### 5.5 输入输出规格

输入图像尺寸：`512 × 512`

ResNet-50 下采样 32 倍后：

- 最终特征图大小约 `16 × 16`

每个特征点预测：

- `18` 个分类参数（9 anchors × 2）
- `36` 个回归参数（9 anchors × 4）

论文给出的输出规格：

- `cls_prob = (18, 16, 16)`
- `bbox_pred = (36, 16, 16)`

### 5.6 损失函数

采用 RPN 标准形式：

\[
L(p_i,t_i)=\sum_i L_{cls}(p_i,p_i^*)+\lambda \sum_i p_i^*L_{reg}(t_i,t_i^*)
\]

其中：

- `L_cls`：前景/背景二分类交叉熵
- `L_reg`：Smooth L1
- `λ = 10`

### 5.7 训练参数

论文设置：

- 数据量：1246
- 输入尺寸：`512 × 512`
- 优化器：Adam
- 学习率：`0.0001`
- 训练 batch：10
- 验证 batch：3
- epoch：100
- 显卡：RTX 2060 SUPER（论文原始实验环境；本项目实际部署建议为 4 张、单卡 24GB+ GPU）

### 5.8 正负样本判定

anchor 与真实框的 IOU：

- `IOU > 0.7`：前景
- `IOU < 0.3`：背景

论文测试时判断检测是否正确的条件也是：

- 预测框与真实框 `IOU > 0.7` 即判为阳性

### 5.9 Proposal 后处理

实现步骤：

1. 将预测框从特征图坐标映射回输入图像坐标。
2. 根据回归参数修正 anchor。
3. 删除越界框。
4. 删除面积过小的框。
5. 执行 NMS。
6. 按前景概率排序，保留前 `128` 个候选框。
7. 取置信度最高的踝关节框作为 ROI。

### 5.10 裁剪 ROI 数据集

训练出踝关节检测模型后，用它对所有非完全粉碎型图像进行批量处理：

1. 输入原始 X 光片。
2. 检出踝关节框。
3. 以该框为中心裁剪 ROI。
4. 保存为后续骨损检测和分割的统一输入数据。

这一步是后续阶段性能提升的关键。

## 6. 阶段 3A：小目标骨损检测

论文在这一部分主要比较：

- Resnet-RPN
- YOLO V3
- 在两者中加入 CBAM / BAM 注意力机制后的效果

### 6.1 任务定义

输入：踝关节裁剪图像

输出：

- 一个或多个骨损边界框
- 每个边界框的置信度

如果某张图预测出了任意骨损框，则可进一步判定该病例为“有骨损”。

### 6.2 两种输入预处理方式

论文专门比较了两种预处理：

#### 方式 A：整图缩放
- 原图直接缩放到 `512 × 512`

#### 方式 B：踝关节裁剪后再缩放
- 先用踝关节检测网络得到 ROI
- 再把 ROI 缩放到 `512 × 512`

论文结论：**裁剪方式显著优于整图缩放方式**。

因此，工程复现时建议默认使用：

- `detect ankle -> crop ROI -> resize 512×512 -> detect bone damage`

### 6.3 训练数据

- 健康数据：511 张
- 骨损数据：735 张
- 测试集共 249 张
- 其中骨损测试样本 148 张，共 370 个独立骨损框

### 6.4 训练参数

论文设置：

- 框架：PyTorch
- 优化器：Adam
- 学习率：`0.0001`
- 输入尺寸：`512 × 512`
- 训练 batch：10
- 验证 batch：3
- epoch：100
- 后处理：NMS
- 正确检测判据：预测框与标签框 `IOU > 0.7`

## 7. YOLO V3 实现步骤

### 7.1 采用 YOLO V3 的原因

论文认为 YOLO V3 对小目标检测更敏感，原因是它采用了：

- 残差主干网络 Darknet-53
- 多尺度检测分支
- 大特征图负责检测更小目标

### 7.2 YOLO V3 基本实现流程

1. 使用 `Darknet-53` 作为 backbone。
2. 从 backbone 不同层提取多尺度特征。
3. 构建 3 个检测头。
4. 每个检测头预测：
   - 边界框坐标
   - objectness
   - 类别概率
5. 将 3 个检测头结果合并。
6. 执行 NMS。
7. 输出最终骨损框。

### 7.3 输出张量形式

单个检测层输出：

\[
N \times N \times [3 \times (4+1+C)]
\]

其中：

- `N × N`：网格大小
- `3`：每格 3 个 anchor
- `4`：边界框参数
- `1`：置信度
- `C`：类别数

在本论文任务中，本质上只需要：

- 骨损 / 非骨损

因此可实现为单类别检测。

### 7.4 损失函数构成

YOLO V3 的总损失由三部分组成：

1. 定位损失 `L_reg`
2. 置信度损失 `L_conf`
3. 分类损失 `L_cls`

总损失形式：

\[
Loss = \sum_{i=0}^{N^2}\sum_{j=0}^{B}(L^{reg}_{ij}+L^{conf}_{ij}+L^{cls}_{ij})
\]

工程实现时直接采用成熟 YOLO V3 loss 即可，不必完全手写论文公式。

### 7.5 YOLO V3 训练步骤

1. 读取 ROI 图像和骨损框标签。
2. 把标签分配到对应尺度的 anchor。
3. 前向传播得到 3 个检测头输出。
4. 计算回归损失、目标置信度损失、类别损失。
5. 反向传播更新模型。
6. 每轮在验证集记录：
   - Recall
   - Precision
   - F1
7. 保存最优权重。

## 8. Resnet-RPN 实现步骤（用于骨损检测）

除了用于踝关节检测，论文也把 Resnet-RPN 用于小目标骨损检测。

### 8.1 实现思路

与踝关节检测阶段相同，只是这里的目标由“踝关节”变为“骨损框”。

步骤：

1. 输入踝关节 ROI 图像。
2. ResNet-50 提取特征。
3. RPN 生成前景候选框。
4. 通过 bbox regression 修正位置。
5. NMS 去重。
6. 输出骨损框。

### 8.2 与 YOLO V3 的关系

论文中 Resnet-RPN 更像一个两阶段检测思想的简化版；YOLO V3 是单阶段检测器。实验结果表明：

- YOLO V3 的整体效果略优于 Resnet-RPN；
- 原因是 YOLO V3 有多尺度检测分支，对小目标更敏感。

因此工程实践中：

- 若追求论文主结果，建议同时复现两者；
- 若只选择一个主模型，优先使用 **YOLO V3 + CBAM**。

## 9. 注意力机制模块实现

论文重点比较了两种注意力模块：

- BAM
- CBAM

目的都是增强小骨损区域的特征表达，抑制背景干扰。

---

## 10. BAM 的实现步骤

### 10.1 结构特点

BAM 采用并行结构：

- 一路做通道注意力
- 一路做空间注意力
- 最后融合

整体表达式：

\[
F' = F + F \otimes \sigma(M_c(F) + M_s(F))
\]

### 10.2 通道注意力实现

按照论文含义，可实现为：

1. 输入特征 `F`，尺寸 `C×H×W`
2. 对空间维做 `Global Average Pooling`
3. 得到 `C×1×1`
4. 输入 MLP
5. 做 BatchNorm
6. 得到通道权重

数学形式：

\[
M_c(F)=BN(MLP(AvgPool(F)))
\]

### 10.3 空间注意力实现

实现步骤：

1. 先用 `1×1` 卷积压缩通道；
2. 再用若干个 `3×3` 空洞卷积扩大感受野；
3. 最后再用 `1×1` 卷积输出单通道空间权重图；
4. 加 BatchNorm。

论文给出的关键信息：

- 第一层卷积：`1×1`
- 中间卷积：`3×3`
- 膨胀率：`d = 4`
- 最后一层：`1×1`
- 输出大小：`1×H×W`

### 10.4 融合方式

1. 将通道注意力和空间注意力结果相加；
2. 过 Sigmoid；
3. 与输入特征逐元素相乘；
4. 再与原始输入相加形成残差输出。

---

## 11. CBAM 的实现步骤

### 11.1 结构特点

CBAM 是串行结构：

1. 先通道注意力
2. 再空间注意力

整体表达式：

\[
F' = M_c(F) \otimes F
\]

\[
F'' = M_s(F') \otimes F'
\]

### 11.2 通道注意力实现

与 BAM 相比，CBAM 的通道注意力同时使用：

- Average Pooling
- Max Pooling

公式：

\[
M_c(F)=\sigma(MLP(AvgPool(F)) + MLP(MaxPool(F)))
\]

实现步骤：

1. 对输入特征分别做全局平均池化和全局最大池化；
2. 两路都送入共享 MLP；
3. 结果相加；
4. 经过 Sigmoid 得到通道权重；
5. 与输入特征逐元素相乘。

### 11.3 空间注意力实现

公式：

\[
M_s(F)=\sigma(f^{7\times7}([AvgPool(F);MaxPool(F)]))
\]

实现步骤：

1. 先在通道维度做平均池化，得到 `1×H×W`
2. 再做最大池化，得到 `1×H×W`
3. 将两者拼接成 `2×H×W`
4. 用一个 `7×7` 卷积生成空间注意力图
5. 经过 Sigmoid
6. 与前一阶段特征相乘

### 11.4 为什么论文更推荐 CBAM

论文实验表明：

- CBAM 和 BAM 都能提升性能；
- 但 CBAM 提升更明显；
- 尤其在降低漏检方面效果更好。

因此工程实现建议优先使用 **CBAM**。

## 12. 将注意力机制接入检测网络

### 12.1 接入 YOLO V3

论文做法：

- Darknet-53 包含多个卷积模块；
- 将 BAM / CBAM 插入到卷积特征提取过程中。

建议实现步骤：

1. 保持 YOLO V3 主体结构不变；
2. 在 backbone 的残差块后插入 CBAM；
3. 或在每个主要卷积模块后插入 CBAM；
4. 重新训练整网；
5. 对比无注意力版本指标。

### 12.2 接入 Resnet-RPN

论文做法：

- ResNet-50 含 16 个 Bottleneck；
- 将 BAM / CBAM 插入每个 Bottleneck 中。

建议实现步骤：

1. 重写 ResNet Bottleneck；
2. 在残差块输出前加上 CBAM；
3. 再把增强后的 backbone 接到 RPN 上；
4. 重新训练检测网络。

## 13. 阶段 3B：踝关节缝隙语义分割

这一阶段的目标不是检测骨折，而是提取踝关节缝隙的几何形态，用于辅助医生判断肌肉/韧带损伤。

### 13.1 为什么要做缝隙分割

论文指出：

- 韧带和肌肉在 X 光片上通常不可直接见；
- 但关节缝隙的几何形态变化可间接反映损伤情况；
- 所以分割关节缝隙可以为临床提供重要参考。

### 13.2 使用的数据

- 总数据：1246 张
- 每张图像来自踝关节 ROI
- 尺寸统一为 `256 × 256`
- 数据增强：以 `0.5` 概率随机水平翻转
- 标签：使用关节缝隙 mask

### 13.3 U-Net 实现步骤

1. 构建编码器：逐层下采样提取语义特征；
2. 构建解码器：逐层上采样恢复分辨率；
3. 使用跳跃连接把浅层细节与深层语义融合；
4. 输出单通道分割掩膜；
5. 经 sigmoid 得到像素级概率图。

### 13.4 U-Net++ 实现步骤

U-Net++ 在 U-Net 基础上增加嵌套跳跃连接。

工程实现思路：

1. 保留编码器与解码器主框架；
2. 在编码器和解码器之间加入密集跳连；
3. 缩小编码层与解码层之间的语义差距；
4. 输出分割结果。

论文公式中：

- `H` 表示卷积操作
- `U` 表示上采样
- `[]` 表示拼接连接

工程上直接使用标准 U-Net++ 实现即可。

### 13.5 分割损失函数

论文描述 U-Net++ 的损失由：

- 二元交叉熵（BCE）
- Dice 系数

组合而成。

建议实现为：

```text
loss = BCE(pred, mask) + DiceLoss(pred, mask)
```

### 13.6 分割训练参数

论文设置：

- 框架：PyTorch
- 输入尺寸：`256 × 256`
- 数据增强：水平翻转概率 `0.5`
- 学习率：`0.001`
- epoch：`250`
- 每个 epoch 记录 loss

论文观察到：

- 大约前 50 个 epoch 验证损失下降明显；
- U-Net++ 在第 68 个 epoch 左右验证损失最低。

### 13.7 分割评估指标

论文使用：

- Dice
- IOU
- Precision
- Recall

公式如下：

\[
Dice(P,G)=\frac{2|P\cap G|}{|P|+|G|}
\]

\[
IOU(P,G)=\frac{|P\cap G|}{|P\cup G|}
\]

几何意义：

- `TP`：预测与标签重叠部分
- `FP`：多预测部分
- `FN`：漏预测部分

因此：

\[
IOU = \frac{TP}{TP+FP+FN}
\]

\[
Dice = \frac{2TP}{2TP+FP+FN}
\]

\[
Precision = \frac{TP}{TP+FP}
\]

\[
Recall = \frac{TP}{TP+FN}
\]

### 13.8 分割推理步骤

1. 输入踝关节裁剪图；
2. resize 到 `256 × 256`；
3. 前向传播得到像素概率图；
4. 通过阈值二值化得到缝隙 mask；
5. 将 mask 叠加到原图上；
6. 输出给临床系统或可视化界面。

## 15. 论文中的关键实验结论及工程启示

### 15.1 裁剪 ROI 比整图缩放更重要

这是论文中最关键的工程结论之一。

原因：

- 骨损本来就小；
- 整图缩放会让骨损变成更小的绝对目标；
- 先裁踝关节再检测，可以保住更多骨损细节。

### 15.2 YOLO V3 略优于 Resnet-RPN

原因：

- YOLO V3 有多尺度检测；
- 对小目标更敏感。

所以若只部署一个骨损检测器，优先选择 **YOLO V3**。

### 15.3 CBAM 优于 BAM

实验显示：

- 两者都能提升精度；
- CBAM 效果更好；
- 对减少漏检更明显。

所以注意力模块首选 **CBAM**。

### 15.4 U-Net 与 U-Net++ 各有特点

论文结论：

- U-Net 在整体平均 Dice 和 Precision 上更高；
- U-Net++ 收敛更稳定；
- 正视图上 U-Net 更强；
- 侧视图复杂干扰较多时，U-Net++有时能保持更完整结构，但边界更模糊。

若只选一个分割模型，可优先部署 **U-Net**。

## 17. 实现时的注意事项

### 17.1 不要跳过踝关节裁剪

如果直接做整图检测，性能会明显下降。

### 17.2 小目标场景要重点调 anchor

因为最小骨损可达 `50 × 50`，建议在复现时：

- 把 anchor 尺寸向小目标倾斜；
- 检查不同尺度检测头是否真的覆盖小目标尺寸。

### 17.3 侧视图缝隙分割更难

论文指出侧视图存在叠影问题，因此：

- 不要只看平均指标；
- 需要单独评估正视图和侧视图；
- 必要时按视角分模型训练。

### 17.4 评价要同时看框级和病例级

骨损检测至少要统计两套指标：

1. **框级指标**：Recall / Precision / F1
2. **病例级指标**：是否判断该病例有骨损

### 17.5 分割模型优先看 Dice 和 Precision

因为临床场景更关心：

- 分割区域是否准确；
- 假阳性是否太多；
- 结构边界是否稳定。

## 19. 一句话总结

论文算法的核心不是单一模型，而是一个**多阶段医学影像辅助诊断流程**：

- 先过滤掉干扰严重的样本；
- 再检测踝关节并裁剪 ROI；
- 再利用带注意力机制的检测网络识别小骨损；
- 最后用语义分割提取关节缝隙几何信息。

从工程角度看，真正最关键的三点是：

1. **先裁踝关节再检测骨损**
2. **小目标检测优先用 YOLO V3 多尺度结构**
3. **用 CBAM 强化目标特征**
