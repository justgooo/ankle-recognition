# 三种识别算法从数据集到“有无患病概率”输出的对比总结

## 1. 文档目的

这份文档把 `docs/` 里的三种方法压缩到同一个比较框架下，只保留你现在最关心的一条主线：

```text
数据集
→ 样本筛选与标注
→ 预处理
→ 特征提取 / 模型推理
→ 输出“有无患病”的概率
```

这里的“患病概率”统一理解为：

- 对二分类方法：`P(患病)` 或 `P(fracture / bone injury)`
- 对检测方法：由检测框置信度汇总成病例级 `P(患病)`
- 对纯分型方法：如果原论文没有“正常类”，则**不能直接得到 `P(患病)`**

---

## 2. 先说结论

如果你准备做“现有论文方法准确率对比”，这三篇里只有 1 篇可以**直接**作为“有病 / 无病”二分类方法比较，1 篇可以**经过统一规则后**作为二分类方法比较，另外 1 篇本质上是**骨折分型**，不适合直接和“有病 / 无病”准确率放在同一张表里。

### 直接可比

- **CNN + SURF 的二分类检测与定位（跟骨 CT 骨折有无判断）**
  - 原生就是二分类
  - 模型直接输出 `P(fracture)` 和 `P(normal)`

### 条件可比

- **基于深度学习的足踝关节骨损辅助诊断算法**
  - 原生是多阶段辅助诊断系统
  - 可以把检测框置信度汇总成病例级 `P(患病)`

### 不建议直接放进“有病 / 无病准确率”主表

- **深度 CNN + 数据增强的 Sanders 分型**
  - 原生任务是 `Type I / II / III / IV` 四分类
  - 数据中没有正常样本，不直接输出 `P(患病)`

---

## 3. 三种方法的统一对比

| 方法 | 影像模态 | 原始任务 | 数据集到概率输出的最短路径 | 是否原生输出 `P(患病)` | 当前文档里是否有可直接引用的准确率 |
|---|---|---|---|---|---|
| Sanders + PCANet | 跟骨 CT | 骨折分型四分类 | CT 切片 → 筛选含跟骨的冠状位 → 形态学预处理 → 数据增强 → PCANet → 四分类 | 否 | 有，但这是**分型准确率**，不是患病二分类准确率 |
| CNN + SURF | 跟骨 CT | 骨折 / 正常二分类 + 定位 | CT 切片 → resize/ZCA → VGG/ResNet 二分类 → 输出 `P(fracture)` | 是 | 当前总结文档没保留最终精确数字，需要回原论文补 |
| 足踝关节骨损辅助诊断 | 足踝 X 光 | 分类过滤 + ROI 检测 + 骨损检测 + 分割 | X 光 → 分类过滤 → 踝关节 ROI → 骨损检测框置信度 → 汇总为 `P(患病)` | 否，需工程汇总 | 当前总结文档主要保留了流程和相对结论，最终二分类准确率需回原论文补 |

---

## 4. 方法一：Sanders 分型 + PCANet

## 4.1 数据集

- 数据来源：14 名患者的跟骨 CT
- 原始切片：约 6131 张
- 最终有效样本：760 张
- 仅保留：
  - `coronal view`
  - 明确包含跟骨主体的切片
- 标签：
  - Type I
  - Type II
  - Type III
  - Type IV

这一步的关键点是：**它的数据默认已经是骨折阳性数据，不包含“正常 / 无病”类。**

## 4.2 从数据集到输出的过程

```text
原始 DICOM CT
→ 转 2D 图像，统一到 360×360
→ 仅保留 coronal 且含跟骨的切片
→ 人工标注 Sanders I/II/III/IV
→ 阈值二值化 + 腐蚀 + 膨胀 + 最大轮廓提取
→ 将骨组织区域映射回原图并居中
→ Augmentor 做旋转 / 形变 / 水平翻转
→ two-stage PCANet 提取特征
→ 分类器输出四分类结果
```

## 4.3 如果强行对齐到“患病概率”

这个方法原生只能输出：

- `P(Type I)`
- `P(Type II)`
- `P(Type III)`
- `P(Type IV)`

它**不能直接输出**：

- `P(无病)`
- `P(有病)`

因为训练数据里本来就没有正常样本。

所以如果你要拿它和其他“有病 / 无病”论文比较，有两个选择：

1. 把它单独放在“骨折分型方法”一栏，不参与二分类准确率主表。
2. 另行加入正常样本，重做二分类版本。

## 4.4 当前文档里能拿到的结果

- 随机划分准确率：约 **92% ~ 95%**
- leave-one-out 且不增强：约 **35%**
- leave-one-out 且增强后：约 **62% ~ 72%**

但这些数字对应的是：

- **Sanders 四分类准确率**
- 不是“有病 / 无病”的准确率

## 4.5 对你的对比实验的意义

这篇更适合作为：

- **“病变严重程度 / 分型识别”基线**

不适合作为：

- **“是否患病”二分类基线**

## 5. 方法二：CNN + SURF 的跟骨 CT 二分类检测与定位

## 5.1 数据集

- 影像类型：跟骨 CT
- 标签：
  - `fracture`
  - `normal`
- 建议划分：
  - train 70%
  - val 15%
  - test 15%
- 注意：
  - 同一患者不能同时进入训练集和测试集

这是三篇里最接近你目标的一篇，因为它从一开始就是**有病 / 无病二分类**。

## 5.2 从数据集到输出概率的过程

```text
原始 CT 图像
→ resize: 512×512 到 224×224
→ 张量化
→ ZCA whitening
→ 预训练 VGG16 / ResNet50 微调
→ softmax / sigmoid
→ 输出 P(fracture) 与 P(normal)
→ 若 P(fracture) 较高，再进入 SURF 定位流程
```

## 5.3 概率输出发生在哪一步

真正的“有无患病概率”来自 **CNN 二分类头**，而不是 SURF。

也就是：

- `P(患病) = P(fracture)`
- `P(无病) = P(normal)`

SURF、FLANN、RANSAC、Canny、Contours 的作用是：

- 在已经判断为骨折的图像上做**定位**
- 不负责生成主诊断概率

## 5.4 这个方法为什么适合做准确率对比

因为它满足以下条件：

- 输入和输出定义清晰
- 原生任务就是二分类
- 概率来自标准分类网络
- 方便统一到 `accuracy / sensitivity / specificity / AUC`

## 5.5 对你的对比实验的意义

这篇最适合作为：

- **CT 条件下的二分类基线**

如果你准备先做一个“论文方法准确率对比主表”，它应该放在主表里。

## 6. 方法三：基于深度学习的足踝关节骨损辅助诊断

## 6.1 数据集

- 影像类型：足踝 X 光片
- 总数：**1852 张**
- 完全粉碎型：606
- 非完全粉碎型：1246
- 非完全粉碎型中：
  - 健康无骨损：511
  - 含骨损：735

这个方法不是一个单独的二分类器，而是一个**多阶段流水线系统**。

## 6.2 从数据集到输出概率的过程

如果只保留和“是否患病”相关的最短链路，它可以压缩成：

```text
原始 X 光片
→ 阶段 1：分类模型过滤完全粉碎型 / 非完全粉碎型
→ 阶段 2：Resnet-RPN 检测踝关节 ROI
→ 阶段 3：YOLO V3 或 Resnet-RPN 检测骨损框
→ 根据检测框置信度汇总病例级患病概率
→ 输出 P(患病)
```

其中真正和“患病概率”最相关的是阶段 3。

## 6.3 需要怎样把它转成 `P(患病)`

这篇原生输出更像是：

- 骨损框位置
- 每个框的置信度
- 可选的关节缝隙分割结果

也就是说，它没有天然给出一个统一的 `P(患病)`。如果你要拿它做对比，需要先定义**病例级概率汇总规则**。

最常用的两种规则：

### 规则 A：最大框置信度

```text
P(患病) = max(score_1, score_2, ..., score_n)
```

适合：

- 一张图里只要出现一个高置信病灶框，就认为患病

### 规则 B：多框并联概率

```text
P(患病) = 1 - ∏(1 - score_i)
```

适合：

- 一张图可能有多个疑似病灶
- 希望把多个中等分数框合成一个更稳定的病例级概率

## 6.4 哪些步骤其实不属于“患病概率”

以下步骤对系统有帮助，但不属于生成主诊断概率的核心路径：

- 踝关节缝隙分割（U-Net / U-Net++）
- 可视化叠加图输出
- 严重骨损过滤后的辅助分流逻辑

如果你的目标是做“有病 / 无病准确率对比”，这些可以保留在备注里，不要混进主对比链条。

## 6.5 对你的对比实验的意义

这篇更适合作为：

- **X 光场景下的多阶段检测型基线**

但在统计准确率时，必须先明确：

- 你到底比较的是**图像级准确率**，还是**病例级准确率**
- 你采用哪一种检测分数汇总规则

## 7. 如果你只关心“数据集到 `P(患病)`”的最短链路

可以把三篇压缩成下面这张表。

| 方法 | 数据集 | 预处理 | 核心模型 | 概率输出点 | 最终能否得到 `P(患病)` |
|---|---|---|---|---|---|
| Sanders + PCANet | 跟骨 CT，760 张有效骨折切片，4 类分型 | 二值化、腐蚀、膨胀、最大轮廓、居中、增强 | PCANet + 分类器 | 四分类头 | 不能直接得到 |
| CNN + SURF | 跟骨 CT，fracture / normal | resize、张量化、ZCA whitening | VGG16 / ResNet50 | 二分类 softmax / sigmoid | 可以直接得到 |
| 足踝骨损辅助诊断 | 足踝 X 光，1852 张 | resize、ROI 检测、裁剪 | ResNet50 + Resnet-RPN + YOLO V3/Resnet-RPN | 检测框 score | 可以汇总得到 |

---

## 8. 你做论文准确率对比时，建议这样分组

## 8.1 主表：有病 / 无病二分类准确率

建议放：

1. **CNN + SURF（直接二分类）**
2. **足踝骨损辅助诊断（检测分数汇总成病例级二分类）**

不建议直接放：

3. **Sanders + PCANet**

因为它不是同一个任务。

## 8.2 附表：病变分型 / 严重程度识别

建议单独放：

1. **Sanders + PCANet**

这样表意最清楚，也最不容易被审稿人或老师质疑“任务定义不一致”。

---

## 9. 如果你必须把三篇都统一成“患病概率”口径

那推荐统一规则如下：

### Sanders + PCANet

- 不直接纳入主表
- 备注：原论文无正常类，无法原生输出 `P(患病)`

### CNN + SURF

- 直接使用分类头输出：
  - `P(患病) = P(fracture)`

### 足踝骨损辅助诊断

- 统一为病例级：
  - `P(患病) = max(detection scores)`
  - 或 `1 - ∏(1 - score_i)`

并在表头明确注明：

- “检测型方法的病例级患病概率由检测框置信度汇总得到”

---

## 10. 最终建议

如果你的目标是做一个**严谨且好解释**的对比实验，最稳妥的做法是：

1. 先把论文方法分成两类：
   - **二分类诊断**
   - **病变分型 / 辅助检测**
2. 主对比表只比较真正输出 `P(患病)` 的方法。
3. Sanders 这篇单独列成“分型方法参考”，不要硬塞进二分类准确率主表。
4. 对多阶段检测方法，提前写清楚病例级概率汇总规则。

一句话概括：

> 三篇里最适合直接做“有无患病准确率”比较的是 **CNN + SURF**；足踝 X 光这篇需要先把检测分数汇总成病例级概率；Sanders 分型这篇本质上不是“有病 / 无病”任务，建议单独成表。
