# D1 / D2 / D4 三篇论文模型架构创新解读与足踝 CT 二分类横向对比

## 分析对象

1. `D1_CT-Based_2.5D_Deep_Learning-Multi-Instance_Learning_for_Predicting_Early_Recurrence_of_HCC_2025.pdf`
2. `D2_Combining_2.5D_deep_learning_and_conventional_features_for_sICH_expansion_2024.pdf`
3. `D4_Halfway_to_3D_Ensembling_2.5D_and_3D_Models_for_Robust_COVID-19_CT_Diagnosis_2026.pdf`

## 这三篇论文的核心路线先说结论

这三篇论文虽然临床任务不同，但它们对你的“足踝 CT 患病 / 无病二分类”非常有参考价值，因为它们实际上分别代表了三条很典型的建模路线：

- D1 代表的是“ROI 中心的 2.5D + MIL 弱 3D 表征”路线。
- D2 代表的是“2.5D 深度特征 + 传统特征联合建模”路线。
- D4 代表的是“2.5D 与 3D 双分支互补 + 域泛化 + 集成”路线。

如果把这三篇论文压缩成一句对你最有用的话：

- D1 最值得借鉴的是“把一例 CT 看成一个由多张关键切片组成的 bag，再做 bag-level 判别”。
- D2 最值得借鉴的是“不要把深度学习和传统特征对立起来，很多时候联合建模比单一端到端更稳”。
- D4 最值得借鉴的是“2.5D 往往比纯 3D 更省数据，而 2.5D 和 3D 的互补集成能进一步提高鲁棒性，尤其适合多中心或扫描协议不一致的场景”。

## 一、逐篇细致分析

## 1. D1：CT-Based 2.5D Deep Learning-Multi-Instance Learning for Predicting Early Recurrence of HCC (2025)

### 1.1 论文任务与建模对象

这篇文章的任务不是直接做病灶分类，而是基于肝癌 CT 动脉期影像预测术后早期复发。它的目标本身和你的任务不同，但它的建模思想对“局灶性病变 + 体层异质性 + 只有病例级标签”的足踝 CT 二分类很有启发。

论文使用 191 例 HCC 患者，先做肿瘤分割，再从肿瘤最大层面附近抽取多张切片，最后通过 2.5D + MIL 的方式进行病例级预测。

### 1.2 每一个文件中的深度学习模型方法

这篇论文的方法链条很清晰，可以拆成 6 步：

1. 手工分割肿瘤 ROI。
2. 以肿瘤最大横截面为中心，选取相邻层面 `±1, ±2, ±4, ±7, ±9`，总共形成 11 张切片。
3. 对每张 2.5D 切片进行裁剪、标准化，再送入 slice-level CNN。
4. 在 slice-level 阶段对比 `ResNet18 / ResNet101 / DenseNet121` 三种网络，最终选择验证集表现最好的 `ResNet18`。
5. 不直接把 slice-level 输出拿来做最终分类，而是把整例患者视为一个 bag，利用 MIL 思想把 11 张切片的预测结果聚合为病例级特征。
6. 聚合后的 MIL 特征再经 `Z-score -> 显著性筛选 -> 高相关剔除 -> Lasso`，最后用 `ExtraTrees` 做最终分类，并用 `SMOTE` 处理类别不平衡。

换句话说，这不是一个“单纯 CNN 端到端直接输出标签”的方法，而是：

`2.5D 切片编码 -> 多实例聚合 -> 机器学习分类器`

### 1.3 网络结构的创新点

这篇论文真正的创新不在 backbone，而在“切片到病例”的组织方式。

#### 创新点 1：2.5D 取样不是简单相邻三层，而是围绕最大病灶层做非均匀多层抽样

它不是常见的 `中心层 + 前后各一层`，而是围绕最大截面取 `±1, ±2, ±4, ±7, ±9`，相当于既保留近邻细节，又覆盖更长程的层间变化。这种设计在数据量不够大、又想保留部分三维空间信息时非常实用。

对足踝 CT 来说，这一点尤其有价值。很多病变并不只出现在单一层面，例如：

- 骨折线在多个层面上延续，但每层形态不同。
- 骨髓水肿、骨皮质中断、关节面塌陷、骨赘、骨囊变等征象可能分散在不同切片。
- 单张切片可能信息不足，但完整 3D 又太吃数据和显存。

因此，D1 的这套“围绕关键层多距离采样”的思想很适合迁移到足踝 CT。

#### 创新点 2：MIL 把病例看成一个由多切片组成的 bag，而不是把所有切片当独立样本

这是 D1 最有价值的部分。

论文没有把 11 张切片逐张投票，而是通过 MIL 聚合整例患者的切片级输出。具体做法是把 slice prediction 转成：

- `Predicted Likelihood Histograms (PLH)`
- `Bag-of-Words (BoW)`
- 再结合 `TF-IDF` 权重

最终形成病例级 MIL 特征。

这个设计的本质是：它不是问“哪一张切片像阳性”，而是在问“这一整例病例在切片分布模式上像不像阳性”。

对于你的足踝 CT 二分类，如果标签是病例级的“患病 / 无病”，而病变征象只在少数层面出现，那么这种 bag-level 建模比简单平均所有切片预测更合理。

#### 创新点 3：把深度学习特征与病理相关性连接起来，增强可解释性

D1 不只做预测，还做了：

- `SHAP` 解释特征贡献
- MIL 特征与 `MVI / Ki-67 / 病理分级` 的相关分析

这说明作者试图证明：模型不是在“黑箱乱猜”，而是在捕捉与肿瘤侵袭性相关的影像模式。

对你的项目来说，虽然未必有病理指标，但这个思路仍然能迁移：

- 可以把模型关注区域与骨折线、骨皮质破坏、关节对位异常、骨赘、囊变等征象做对应。
- 可以用 Grad-CAM、attention heatmap 或关键切片回溯去验证模型是否真的在看病灶。

### 1.4 这篇方法的强项与短板

强项：

- 在 2D 和 3D 之间找到了不错的折中。
- 很适合病例级标签、切片级弱标注的任务。
- 强调异质性建模，而不是只看单层特征。
- 可解释性比纯黑箱 3D CNN 更强。

短板：

- 依赖 ROI 分割，前处理成本较高。
- MIL 聚合仍然是基于预测结果和词袋思想，不是更现代的 attention MIL。
- 最终分类器是 `ExtraTrees`，虽然稳，但深度端到端优化能力有限。
- 只关注 ROI，可能忽略 ROI 周边上下文，例如关节邻近结构、骨皮质连续性、软组织反应等。

### 1.5 对你的足踝 CT 项目最有帮助的创新点

我认为 D1 对你最有价值的 3 个点是：

1. `关键层周围多距离采样`
   适合足踝这种局部病变跨层延续、但全 volume 又较大且冗余多的任务。

2. `病例级 MIL 聚合`
   如果你的标签是病例级患病 / 无病，而病变并不占据整个 volume，那么 MIL 很可能比“所有切片平均”更强。

3. `解释性回溯`
   医学任务里非常重要，尤其足踝 CT 往往需要让临床相信模型在看骨病灶而不是背景噪声。

### 1.6 我对 D1 的迁移建议

如果你做足踝 CT 二分类，我不建议原封不动照搬它的 `PLH + BoW + TF-IDF + ExtraTrees` 全套，而是建议保留它的结构思想，升级成更适合当前任务的版本：

- 保留“围绕关键层的多切片输入”。
- 保留“病例级 MIL 聚合”。
- 把传统 BoW 聚合替换成 `attention-based MIL` 或 `transformer-based slice aggregation`。
- 如果没有精确病灶标注，可先用骨区粗定位、最大异常候选层、或解剖区域模板生成 weak ROI。

## 2. D2：Combining 2.5D deep learning and conventional features for sICH expansion (2024)

### 2.1 论文任务与建模对象

这篇论文研究的是自发性脑出血早期扩大的预测。它和 D1 一样也是 CT 任务，但它的亮点不在 MIL，而在“2.5D 深度特征”和“临床 / 影像学 / 影像组学”联合建模。

从你的应用视角来看，D2 更像是在回答一个问题：

“如果深度学习特征已经不错，是否还有必要把传统特征和临床信息再加回来？”

论文的答案是：有必要，而且通常会更稳。

### 2.2 每一个文件中的深度学习模型方法

D2 的方法可以拆成 7 步：

1. 基于血肿 3D mask 得到 ROI。
2. 不是取连续相邻层，而是取血肿在 `axial / coronal / sagittal` 三个正交平面上的最大切面，构成所谓 `2.5D mask`。
3. 对这 254 例患者共得到 `254 x 3 = 762` 张 ROI 图像。
4. 用多个 2D CNN 进行预训练和比较，包括 `AlexNet, DenseNet121, GoogleNet, MNASNet0_5, MobileNet_V2, ResNet50, SqueezeNet1_0, VGG19`。
5. 最终选用 `ResNet50` 作为最优 backbone，不是直接拿最后分类结果，而是提取倒数第二层即 average pooling 层特征。
6. 对深度特征做 `PCA` 降到 32 维，再做 `Z-score / 相关性筛除 / Lasso`。
7. 再把深度特征与 `临床特征 + 放射学征象 + radiomics` 联合，使用 11 种机器学习算法建模，最终最优是 `UNI signature (SVM)`。

这篇论文的核心并不是“让 ResNet50 直接输出分类标签”，而是把 ResNet50 当作特征提取器，再与其他信息源做 late fusion。

### 2.3 网络结构的创新点

#### 创新点 1：用三正交最大切面构造 2.5D 表征

D2 的 2.5D 和 D1 不同。

D1 是沿同一方向围绕关键层采样。
D2 则是从三维 ROI 中提取：

- 最大轴位面
- 最大冠状面
- 最大矢状面

这相当于把同一病灶从三个解剖视角表达出来。

对于足踝 CT，这个思路非常值得借鉴，因为很多骨科病变本来就是强烈依赖三维解剖关系的，例如：

- 骨折线在轴位最清楚，但关节面塌陷在矢状位更明显。
- 距骨、跟骨、踝穴、下胫腓联合的异常，在不同平面可见性不同。
- 单平面容易漏掉解剖关系，三平面互补更接近临床阅片习惯。

#### 创新点 2：深度学习模型不是终点，而是“深度特征发生器”

这一点非常实用。

论文不是把 CNN 当终极分类器，而是用 `ResNet50` 的倒数第二层输出作为深度特征，然后再和其他特征统一建模。

这种思路的价值在于：

- 深度网络负责提取复杂表征。
- 传统机器学习负责在小样本条件下做更稳的判别。
- 多源特征可以一起进入统一分类器，而不是各自为战。

对医学影像尤其是小样本任务，这种做法往往比端到端硬训更稳，也更容易解释。

#### 创新点 3：联合建模优于单一模态建模

D2 最终比较了：

- Clinic model
- Radiology model
- Radiomics model
- DL model
- Joint UNI model
- Nomogram

结果中最强的是联合模型 `UNI signature (SVM)`，测试集 AUC 达到 `0.929`，明显高于单独 DL 模型的 `0.857`。

这说明一个很重要的现实问题：

深度学习并不一定应该单打独斗。

如果你的足踝 CT 项目里除了 CT 图像之外，还能拿到：

- 年龄、性别、外伤史、病程
- 肉眼放射学征象
- ROI 大小、骨密度、骨皮质连续性等人工结构化特征

那么很可能联合模型会比纯 CNN 更稳。

#### 创新点 4：在算力受限条件下完成相对高性能建模

论文明确提到其方案适合在普通办公电脑上训练和使用。这一点不是“算法创新”，但对很多真实医学团队非常关键。

它说明：如果你的数据量不大、GPU 资源有限，那么“2.5D 特征提取 + 特征选择 + SVM/MLP/LR”是很实际的路线。

### 2.4 这篇方法的强项与短板

强项：

- 三视图 2.5D 表征很适合三维解剖结构。
- 多源信息融合能力强。
- 小样本下鲁棒性较好。
- 算力需求相对可控。

短板：

- 依赖准确 ROI / mask。
- 预训练 backbone 与后续分类是分离的，不是端到端。
- PCA + Lasso + SVM 这条链虽然稳，但可能损失部分非线性高阶交互。
- 如果临床特征质量不高，联合模型的收益会打折。

### 2.5 对你的足踝 CT 项目最有帮助的创新点

我认为 D2 最值得你借鉴的是以下 4 点：

1. `三正交平面最大切面 2.5D`
   这和足踝解剖高度匹配，几乎是天然适配。

2. `用 CNN 提特征，而不是只盯着 end-to-end 分类`
   如果你的样本不大，这个策略很稳。

3. `深度特征 + 传统特征联合`
   足踝 CT 中一些规则化征象很有价值，例如骨折线是否跨关节面、骨皮质是否中断、是否有碎裂、关节间隙是否异常。

4. `多算法比较再选最优`
   医学小样本任务里，SVM / LR / MLP 往往并不比深层端到端差。

### 2.6 我对 D2 的迁移建议

如果你的目标是做一个实用且容易起量的足踝 CT 二分类系统，我认为 D2 是非常适合作为第一阶段方案的参考论文。

推荐的迁移方式是：

- 先做三平面 2.5D 输入。
- 用 `ResNet50` 或更现代的 encoder 提取特征。
- 再把这些深度特征与少量高价值结构化特征联合。

可加入的结构化特征例如：

- 病灶体积或异常区域面积
- 骨皮质不连续计数
- 关节面对位异常程度
- 距骨、跟骨、胫骨远端等部位的骨密度或纹理统计
- 年龄、受伤机制、检查时间等临床变量

如果你的数据规模偏小，我甚至会优先推荐你先做 D2 风格的路线，而不是一开始就做复杂 3D 网络。

## 3. D4：Halfway to 3D: Ensembling 2.5D and 3D Models for Robust COVID-19 CT Diagnosis (2026)

### 3.1 论文任务与建模对象

D4 做的是胸部 CT 的 COVID-19 检测和多分类任务，和足踝病变在病种上差异较大，但它的架构思想是三篇里最“现代”的。

它关注的不只是分类精度，还特别关注：

- 多中心域偏移
- 不同来源数据的鲁棒性
- 公平性和泛化性

如果你的足踝 CT 数据来自不同机器、不同医院、不同窗宽窗位习惯，D4 的思路会非常有启发。

### 3.2 每一个文件中的深度学习模型方法

D4 是一个明确的双分支混合框架：

#### 预处理

1. 从原始 axial CT 切片重建 3D volume。
2. 去掉重复切片。
3. resize 到统一的 `128 x 128 x 128`。
4. 使用 3D Gaussian 去噪和 mask sharpening。
5. 灰度归一化到 `[0,255]`。

#### 3D 分支

1. 使用单通道输入的 `3D ResNet-18`。
2. 先做第一阶段的域泛化预训练，使用 `VREx (Variance Risk Extrapolation)`。
3. VREx 阶段的目标是让不同 domain 上的 loss 方差更小，从而学到更 domain-invariant 的特征。
4. 第二阶段再进行任务微调，使用 `cross-entropy + supervised contrastive learning`。
5. 同时加入 `MixUp` 增强泛化。

这条支路的本质是：

`3D volume -> 3D CNN -> 域鲁棒表征`

#### 2.5D 分支

1. 从每个 3D volume 中提取 `axial / coronal / sagittal` 三个平面的切片。
2. 每个平面均匀采样 `8-12` 张切片。
3. 每张切片 resize 到 `224 x 224`。
4. 用 `DINOv3` 预训练 Vision Transformer 做特征编码。
5. 各视图分别编码，再做 multi-view feature fusion。

训练不是一步完成，而是三阶段：

1. 冻结 backbone，只训练分类头。
2. 逐步解冻上层 transformer。
3. 全网络端到端微调。

其本质是：

`多视图 2.5D 切片 -> 预训练 ViT 编码 -> 视图级特征融合`

#### 最终融合

最后不是特征拼接，而是对 `2.5D 分支` 和 `3D 分支` 的输出进行 `logit-level ensemble`，也就是在决策层做集成。

### 3.3 网络结构的创新点

#### 创新点 1：2.5D 与 3D 并行建模，不让二者互相替代，而是互补

这篇论文很重要的一点是它没有陷入“2.5D 和 3D 谁更好”的二选一思维，而是把二者并联起来。

作者认为：

- 3D 模型擅长全局体积结构。
- 2.5D 模型更容易捕捉清晰的 slice-level 模式，而且更容易利用大规模预训练视觉模型。

这和很多医学影像任务的真实情况非常一致。

对于足踝 CT：

- 3D 更擅长看整体骨性排列、关节关系、空间连续性。
- 2.5D 更擅长看骨折线、细小皮质中断、局部纹理、边缘异常。

所以这篇论文给你的启发非常直接：不要过早在 2.5D 和 3D 之间二选一，很多时候最佳方案是“双分支 + 集成”。

#### 创新点 2：2.5D 分支使用 DINOv3 这类强预训练视觉 backbone

这点很值得重视。

传统医学影像论文常常直接拿 ResNet 从头训，或者 ImageNet 预训练后直接微调。但 D4 使用的是更强的自监督预训练视觉 transformer `DINOv3`。

这意味着：

- 2.5D 切片并不是简单的“退而求其次”，反而可以借到自然图像或大规模预训练模型的表示能力。
- 在医学数据有限时，强预训练 backbone 往往比从头训练 3D CNN 更稳。

如果你手头的足踝 CT 数据量有限，这个策略非常值得借鉴。

#### 创新点 3：3D 分支引入域泛化训练

VREx 是 D4 很关键的亮点。它不是只优化平均 loss，而是减少不同来源 domain 之间的风险差异。

这对于足踝 CT 非常重要，因为你的数据可能存在：

- 不同医院扫描协议差异
- 不同重建核
- 不同层厚
- 不同厂商设备
- 不同 FOV 和患者摆位

如果将来要做跨中心泛化，D4 的 `VREx + contrastive + MixUp` 这套训练思想会比单纯堆 backbone 更有价值。

#### 创新点 4：通过 ensemble weight 在精度、鲁棒性、公平性之间做平衡

D4 在测试集上不仅用了 ensemble，还尝试了不同权重：

- `Ens (0.3)`
- `Ens (0.5)`
- `Ens (0.7)`

这意味着最终系统不是死板的，而是可以根据任务偏好去调：

- 更偏向 2.5D 还是更偏向 3D
- 更偏向总体性能还是某些子人群的公平性

对你的项目来说，这提供了一个非常实用的工程思路：

最终上线模型不一定非得是单一 checkpoint，也可以是不同视图 / 不同输入粒度模型的加权集成。

### 3.4 这篇方法的强项与短板

强项：

- 架构现代，兼顾 2.5D 与 3D。
- 预训练 backbone 利用充分。
- 对多中心域偏移更敏感，泛化思路更成熟。
- 集成策略清晰，可扩展性强。

短板：

- 整体训练复杂度最高。
- 计算成本明显高于 D1 和 D2。
- 需要更规范的数据预处理与训练管理。
- 论文任务是胸部 CT，局部小骨病变与肺部弥漫病变在视觉模式上并不完全一致。

### 3.5 对你的足踝 CT 项目最有帮助的创新点

我认为 D4 对你最有帮助的是：

1. `三平面多视图 2.5D`
   和足踝解剖天然契合。

2. `强预训练 slice encoder`
   在样本有限时价值很大。

3. `2.5D + 3D 双分支互补`
   非常适合作为后续增强版架构。

4. `域泛化训练`
   如果你未来考虑多中心推广，这个价值很高。

### 3.6 我对 D4 的迁移建议

如果你的数据量中等以上、并且有 GPU 资源，我非常建议把 D4 作为“第二阶段增强版方案”的主要参考。

适合你的迁移版本可以是：

- 2.5D 分支：三平面多切片 + 预训练 encoder。
- 3D 分支：对足踝 ROI 做 3D patch 或 3D volume 分类。
- 最终层：logit-level ensemble。

如果数据量还不够大，则不必一步到位上双分支，可先上 2.5D 多视图模型，后期再补 3D 分支。

## 三、结合你的“足踝 CT 患病 / 无病二分类”，我认为最值得迁移的创新点

## 1. 优先级最高：D2 + D4 的“三平面 2.5D”思想

这是我最推荐你先做的部分。

原因很简单：

- 足踝的解剖结构非常依赖三平面。
- 纯 2D 容易漏解剖关系。
- 纯 3D 对数据量和算力要求更高。
- 三平面 2.5D 通常是最具性价比的折中点。

### 推荐实现方式

- 从每例 CT 中提取 axial / coronal / sagittal 三个平面。
- 如果有 ROI，就围绕 ROI 取关键层。
- 如果没有 ROI，就做骨区裁剪后在三平面均匀采样。
- 三个平面的特征做 attention fusion 或 transformer fusion。

## 2. 如果病灶只占少数层面：引入 D1 的 MIL 思想

足踝 CT 中有些病变是典型“少数切片决定标签”的，比如：

- 隐匿骨折
- 细小骨皮质裂隙
- 局部骨缺损
- 小范围关节面塌陷

这时若直接平均所有切片特征，病灶信息很容易被淹没。D1 的 MIL 思想就很合适。

### 推荐实现方式

- 把一例 CT 看成一个 bag。
- 每张关键切片输出一个 embedding。
- 用 attention MIL 聚合成病例级 embedding。
- 最后做二分类。

这会比简单 mean pooling 更适合“局灶异常 + 病例级标签”的情况。

## 3. 如果能获得临床或规则化影像特征：借鉴 D2 的联合建模

如果你除了 CT 图像之外还能拿到一些辅助变量，我强烈建议尝试联合建模。

可考虑加入的变量包括：

- 年龄、性别
- 急性外伤 / 慢性劳损信息
- 患侧 / 部位标签
- 放射科医生记录的征象
- ROI 体积、骨密度统计、边缘粗糙度、皮质连续性指标

这类信息在医学任务中常常能提供稳定增益。

## 4. 如果数据来自不同医院或不同扫描协议：借鉴 D4 的域泛化训练

这是很多医学项目后期一定会遇到的问题。

单中心训练出来的模型，在另一个中心往往会掉点。D4 的启发是：

- 不要只盯着训练集准确率。
- 要提前把“跨设备、跨中心、跨协议”作为目标。

### 可以考虑的做法

- `MixUp`
- `supervised contrastive learning`
- domain-aware sampling
- domain generalization 方法，如 `VREx`

## 5. 最终工程形态上，推荐从单分支到双分支逐步演进

我不建议你一开始就上 D4 的全量双分支框架，因为复杂度较高。

更合理的路线是：

### 第一阶段：高性价比基线

- 三平面 2.5D 输入
- 单个 backbone
- 病例级平均或 attention fusion
- 先把稳定性和数据清洗做好

### 第二阶段：针对局灶病变优化

- 引入 D1 风格的 MIL
- 重点提升对少数异常切片的敏感性

### 第三阶段：追求上限与泛化

- 加入 3D 分支
- 做 2.5D + 3D ensemble
- 尝试域泛化训练

---

## 四、如果让我给你的项目做方法路线选择，我会这样排优先级

## 方案 A：最推荐的起步方案

`D2 的三平面 2.5D + D1 的病例级聚合`

原因：

- 适合足踝解剖。
- 兼顾效率与效果。
- 对数据量要求相对温和。
- 易于解释和调试。

具体建议：

- 三平面各采样若干关键切片。
- 用 `ResNet50`、`ConvNeXt` 或预训练 ViT 做编码。
- 用 `attention pooling / MIL pooling` 做病例级聚合。
- 先完成稳健 baseline。

## 方案 B：如果你有更多数据和显存

`D4 的 2.5D + 3D 双分支`

原因：

- 能同时利用局部纹理和整体空间关系。
- 更适合做上限冲击。

具体建议：

- 2.5D 分支负责细节。
- 3D 分支负责整体结构。
- 最后做 logit-level ensemble。

## 方案 C：如果你有较丰富的临床 / 结构化信息

`D2 的联合模型`

原因：

- 医学场景里结构化变量常常很有帮助。
- 对小样本尤其友好。

具体建议：

- 深度影像特征和结构化变量分别建模。
- 再做 late fusion 或统一分类器。

## 五、我认为三篇论文里最适合你项目直接吸收的创新点清单

### 可以直接吸收

1. `三平面 2.5D 表征`
2. `病例级 MIL 聚合`
3. `强预训练 slice encoder`
4. `2.5D 与 3D 集成`
5. `多源特征联合建模`
6. `可解释性分析`

### 不建议原封不动照搬

1. D1 的 `PLH + BoW + TF-IDF` 聚合全流程
   原因是现代 attention MIL 往往更自然。

2. D2 的长链式 `PCA + Lasso + 多算法穷举`
   适合作为实验对照，但未必是最终系统的最佳维护方案。

3. D4 的完整复杂训练策略一次性全部上齐
   如果当前数据量和算力不足，容易把工程复杂度拉得过高。

## 六、最终结论

如果你的目标是做“足踝 CT 患病 / 无病二分类”，从这三篇论文中我最推荐的总体方向是：

### 最优先借鉴

`D2 的三平面 2.5D 输入方式`

因为它与足踝的三维解剖最匹配，而且实现成本相对低。

### 第二优先借鉴

`D1 的病例级 MIL 聚合`

因为足踝病变往往只出现在少数切片，MIL 对这类任务很有帮助。

### 第三优先借鉴

`D4 的 2.5D + 3D 集成和域泛化思路`

这更适合在你完成第一版稳定模型后，再向更高上限和更强泛化推进。

如果只给一个简洁的建模建议，我会建议你优先尝试：

`三平面 2.5D + attention/MIL 聚合 + 结构化特征可选融合`

如果后续数据规模和算力允许，再升级到：

`2.5D 多视图分支 + 3D 分支 + logit-level ensemble`

这会是从当前三篇论文里提炼出来、最适合你足踝 CT 二分类项目的一条实战路线。
