- `C1` 最适合给你“如果多视角已经准备好了，如何把跨视角关系建模得更强”

## 论文 1：XFMamba（MICCAI 2025）

### 1.1 论文解决的问题

这篇论文研究的是 **多视图医学图像分类**。作者不是做单张图分类，而是针对一个病例有两张不同 view 图像的情况，学习“每个 view 的信息”和“不同 view 之间的互补关系”。

它验证的数据集包括：

- MURA：肌骨异常二分类
- CheXpert：胸片多标签分类
- CBIS-DDSM：乳腺钼靶良恶性二分类

所以它本质上和你的任务是最接近的一类思路：**不是只把多视角当作数据堆叠，而是把跨视角关系当成模型重点**。

### 1.2 深度学习模型方法

整体是一个 **纯 Mamba 风格的多视图分类网络**，作者称为 `XFMamba`。它由两部分组成：

1. **四阶段多尺度编码器**
2. **两阶段级联融合模块**

具体流程如下：

1. 两个不同 view 的灰度图分别进入两个分支
2. 每个分支都通过四阶段 encoder 提取多尺度特征
3. 在融合阶段，先做一次浅层跨视图融合
4. 再做一次深层全局融合
5. 最后送入分类头输出结果

编码器部分：

- 采用 `VMamba` 作为 backbone
- 通过 patch partition 把输入转成 feature map
- 经过 3 次下采样和多层 `VSSM` 提取多尺度特征
- `VSSM` 内部由 `Linear + Depth-wise Conv + SiLU + SS2D` 构成
- `SS2D` 用于建模长程空间依赖

训练细节上：

- 输入统一 resize 到 `224 x 224`
- Adam，初始学习率 `1e-4`
- weight decay `1e-5`
- batch size `16`
- 训练 `100` 个 epoch
- encoder 使用 VMamba 预训练权重初始化

### 1.3 网络结构创新

这篇论文真正的创新不在于“用了 Mamba”，而在于 **怎么把 Mamba 改造成多视图融合网络**。

#### 创新点 1：两阶段融合，而不是一次性拼接

作者把多视图融合拆成：

- **浅层融合**：局部跨视图交互
- **深层融合**：全局语义整合

这比医学影像里常见的：

- early fusion：输入层拼接
- late fusion：最后分数平均
- 简单 concat/add：中间粗暴拼接

更细。它的逻辑是：

- 先让两个 view 在局部层面“看见彼此”
- 再让融合后的表示在更高层语义空间里统一建模

这对足踝 CT 很重要，因为你的病变信号往往既有 **局部骨皮质/关节面异常**，也有 **整体结构关系改变**。

#### 创新点 2：CVSM block 做浅层 cross-view swapping

`CVSM`（Cross-View Swapping Mamba）是它的第一层融合。

核心思想不是简单相加，而是：

- 对两个视角的 feature 做线性层、深度卷积和 SiLU 处理
- 按通道掩码进行 **交错式 interleaving**
- 某些通道保留本视图信息，某些通道替换成另一视图的信息
- 之后再进入各自的 Mamba block 提取跨视图的长程空间依赖

作者还加入了一个比较巧的设计：

- 使用共享 `SE` 通道注意力
- 但不是“自己给自己加权”
- 而是 **view1 的全局上下文去缩放 view2 的通道，反之亦然**

这相当于做了一种 **cross-attentive channel recalibration**。它的价值在于：

- 保留每个视角的独立性
- 又让另一视角来决定“哪些通道更重要”

对于足踝 CT，如果你做：

- 轴位/冠状位/矢状位三平面
- 骨窗/软组织窗双分支
- 原始切片/局部病灶 crop 双视角

这个思想都很适合迁移。

#### 创新点 3：MVCM block 做深层 holistic fusion

`MVCM`（Multi-View Combination Mamba）是第二层融合。

它不是只接两个 view，而是构造三条分支：

- 融合分支
- view1 分支
- view2 分支

然后通过：

- Linear
- Depth-wise Conv
- SiLU
- 多分支 selective scan

来完成更深层的全局融合。

其中最关键的一点是：作者让融合分支中的系统矩阵 `C_fuse` 去帮助解码两个单视图分支的 hidden state。也就是说，**融合表示反过来指导单视图表示的更新**，而不是只有单向的信息汇总。

这其实很像在说：

- 单个 view 不再独立完成表征
- 融合上下文成为每个分支的“共享语义先验”

这对骨科 CT 类任务尤其有启发，因为很多病变不是某一层切片独立定义的，而是要结合：

- 关节间隙
- 皮质连续性
- 对位对线
- 周围骨质反应

这些跨切面、跨局部区域的上下文。

### 1.4 实验里验证了什么

作者的 ablation 非常有价值：

- 单独 lateral view：AUROC `0.8961`
- 单独 frontal view：AUROC `0.9081`
- early fusion：`0.9090`
- late fusion：`0.9092`
- cross-fusion + concat：`0.9129`
- cross-fusion + add：`0.9136`
- 去掉 MVCM 的 cross-fusion：`0.9144`
- 完整 XFMamba：`0.9184`

这说明三个结论：

1. 多视图明显优于单视图
2. 不是“有融合就行”，**融合方式本身决定上限**
3. 作者提出的双阶段 cross-fusion 确实优于 early/late fusion 和简单 concat/add

### 1.5 对你的足踝 CT 项目最有帮助的点

我认为它对你最有帮助的，不是整套 Mamba 都搬过去，而是下面 3 个思想：

#### 可迁移点 A：多平面不是简单堆叠，而是应该显式建模跨平面关系

如果你的输入来自 CT volume，你完全可以构造：

- 轴位 slab
- 冠状位 slab
- 矢状位 slab

然后不要只做：

- 直接通道拼接
- 简单平均投票

而是显式做跨平面特征交互。

#### 可迁移点 B：分两级融合比一次性融合更合理

足踝疾病二分类里，病灶可能同时包含：

- 微小骨折线、骨赘、骨皮质毛糙等局部征象
- 排列异常、关节面受累、整体形态改变等全局征象

所以建议你考虑：

- 先局部跨平面融合
- 再全局语义融合

这比一开始就把三平面硬拼在一起更符合医学影像判读逻辑。

#### 可迁移点 C：用另一视角去重标定本视角通道

这个 cross-view channel reweighting 很适合医学场景。因为很多时候：

- 某个平面上信号弱
- 但另一个平面上证据很强

让“强证据平面”去调节“弱证据平面”的通道权重，往往比各分支独立学习更稳。

### 1.6 我对它的迁移评价

优点：

- 思想先进，适合标准化多视角输入
- 对二分类同样适用
- 对局部与全局信息兼顾得比较好

局限：

- 对数据量和训练稳定性要求比普通 CNN 更高
- 你必须先把多视图输入定义好，否则它的优势发挥不出来
- 如果你的样本量不大，直接上 Mamba 可能不如轻量 CNN/3D CNN 稳

结论：

- 适合作为 **第二阶段增强模型**
- 不建议直接作为你项目的第一版起步模型

## 论文 2：Automated detection of radiolucent foreign body aspiration on chest CT using deep learning（2025）

### 2.1 论文解决的问题

这篇论文研究的是 **胸部 CT 上 radiolucent foreign body aspiration 的自动检测**。难点在于异物在 CT 上不明显，纯看片子容易漏诊。

作者没有直接对整幅 CT 生硬分类，而是把问题拆成：

1. 先做 **气道树分割**
2. 再把分割出的 3D 气道模型从多个角度渲染成 2D 快照
3. 用轻量 CNN 做二分类

这和你的足踝 CT 二分类高度相关，因为你的任务同样可能遇到：

- 病灶小
- 背景结构复杂
- 原始 volume 信息冗余大

### 2.2 深度学习模型方法

整体是一个 **两阶段 pipeline**：

1. `MedpSeg` 做气道 3D 分割
2. `ResNet-18` 对多视角快照做二分类

#### 第一阶段：MedpSeg 气道分割

作者使用 `MedpSeg` 作为 airway segmentation 模型。其结构特征包括：

- Encoder-decoder 架构
- Skip connection
- Residual block
- Decoder 端加入 channel-wise attention
- 每个 encoder block 由两层 `3D Conv + BN + ReLU` 组成
- 通过 `3D MaxPool (2 x 2 x 2)` 下采样
- Decoder 用 transposed convolution 上采样
- 最后用 `1 x 1 x 1 conv + sigmoid` 输出二值 mask

这一步的意义非常大，因为它把分类任务先约束到一个更有临床意义的结构域里。

#### 第二阶段：多视角分类

分类阶段不是用原始 3D CT 直接训练，而是：

1. 对分割后的 3D 气道做表面重建
2. 从多个视角采样生成 `12` 张 2D snapshots
3. 每张快照输入 `ResNet-18`
4. 对 `12` 个视角的 SoftMax 概率求平均，得到病人级预测

分类头细节：

- backbone：ImageNet 预训练 `ResNet-18`
- 结构：四个 residual blocks + BN + ReLU + GAP
- 头部：`256-unit dense layer + dropout(0.5) + SoftMax`

训练设置：

- Adam，初始学习率 `1e-4`
- 验证集 loss 5 个 epoch 不提升就衰减 10 倍
- 最多 100 epoch
- 10 个 epoch 不提升则早停
- batch size `16`
- 五折交叉验证
- 最终以最佳验证集 F1 选模型

### 2.3 网络结构创新

这篇论文最大的创新不是 backbone，而是 **把结构先验显式注入分类 pipeline**。

#### 创新点 1：先分割，再分类，而不是直接拿原图硬分类

作者先把 CT 空间缩到 “气道相关结构” 上，再分类。这样做有几个好处：

- 去掉大量无关背景
- 提升病灶和目标结构的空间对应性
- 把“难以直接观察的 subtle sign”转成“结构异常模式”

对于足踝 CT，这个思想非常有价值。你完全可以把：

- 踝关节区骨结构
- 胫骨远端、腓骨远端、距骨、跟骨
- 关节面或特定 ROI

先用分割或粗定位提出来，再做分类。

#### 创新点 2：把 3D 结构转成多视角 2D snapshots

这一步非常实用。它绕开了直接用 3D CNN 的两个痛点：

- 计算开销大
- 小样本时容易过拟合

作者把 3D airway model 从不同角度渲染成 2D 图，再用成熟的 2D CNN 做分类，相当于：

- 保留了 3D 结构信息
- 同时享受 2D backbone 的稳定训练和预训练优势

这其实很适合你的足踝 CT。你可以考虑：

- 三正交平面 slab
- 多角度 MIP
- 骨表面重建后的多视角投影
- 病灶中心周围多视角 patch

#### 创新点 3：多视角投票不是花哨设计，而是直接带来显著收益

作者做了 pipeline ablation：

- 原始 axial CT baseline：Accuracy `72.3%`，F1 `44.6%`
- 加 segmentation mask：Accuracy `75.8%`，F1 `57.3%`
- 改成 6 视角 reduced multi-view：Accuracy `79.6%`，F1 `59.6%`
- 再加 augmentation：Accuracy `85.4%`，F1 `65.9%`
- 完整 12 视角 pipeline：Accuracy `90.0%`，F1 `74.1%`

这说明：

1. 结构先验有用
2. 多视角比单视角更有用
3. 数据增强和多视角是协同增益，不是相互替代

#### 创新点 4：对小数据集，作者反而选轻量 ResNet-18，而不是更重模型

作者比较了：

- ResNet-18
- EfficientNet-B0
- DenseNet-121
- ViT-B/16
- Swin-T

结论是 `ResNet-18` 在性能和计算代价之间最均衡。作者明确指出 transformer 类模型在该任务上 precision 和整体 F1 不如 ResNet-18，原因之一是参数复杂、对小数据更敏感。

这个结论对你非常重要，因为足踝 CT 二分类如果样本量不大，**先把表示做对、ROI 做对、视角做对，往往比一味上大模型更有效**。

#### 创新点 5：专门为多视角输入设计了 view dropout

作者在图像级增强中加入：

- 仿射变换
- circular occlusion masking
- color jitter
- **view dropout**

其中 view dropout 指的是：

- 每个样本本来有 12 个视角
- 训练时随机丢弃其中 1 到 2 个视角

这会迫使模型：

- 不能过度依赖某一个固定角度
- 对部分信息缺失更鲁棒

这对足踝 CT 非常值得借鉴，尤其是当：

- 某些切面质量不稳定
- 某些重建角度对不同病例不一致
- 某些 plane 对病灶可见性波动较大

### 2.4 对你的足踝 CT 项目最有帮助的点

这篇论文是我认为最值得你借鉴的一篇。

#### 可迁移点 A：先验结构约束优先于盲目端到端

足踝 CT 里很多无关信息会干扰分类，例如：

- 小腿远端非目标区域
- 背景软组织
- 扫描床与金属伪影

所以建议你尽量先做：

- 粗定位 ankle ROI
- 或骨/关节结构分割
- 或至少 landmark-guided crop

然后再分类。

#### 可迁移点 B：把 3D volume 变成更稳定的多视角表示

如果直接做 3D CNN，你很可能会遇到：

- 显存压力
- 小样本过拟合
- slice 数不一致

你可以借鉴 C2 设计一条更稳的路线：

- 从 CT volume 中裁出 ankle ROI
- 生成轴位/冠状位/矢状位厚层 slab
- 再补若干 oblique 或 MIP view
- 最后做 patient-level 多视角聚合

#### 可迁移点 C：病人级预测应该由多视角聚合完成

你的最终标签是病人级二分类，未必要让单张切片独立承担全部任务。像 C2 这样：

- 单视角只学局部证据
- 多视角概率平均或加权平均得到病人级判定

很适合临床任务。

### 2.5 我对它的迁移评价

优点：

- 非常适合小样本医学 CT
- 强调 ROI/结构先验，临床可解释性较好
- 轻量 backbone，落地性强

局限：

- 如果你的疾病并不依赖显式结构分割，完整复现这条路线的前半段成本较高
- 多视角快照如何定义，会显著影响上限
- 它的结构先验来自“气道树”，你需要换成“骨-关节结构先验”

结论：

- 这是 **最适合作为你项目主线参考** 的论文

## 论文 3：MMIDFNet（2022）

### 3.1 论文解决的问题

这篇论文研究的是 **多模态 MRI 下的胶质瘤亚型分类**。作者使用四种 MRI 模态：

- T1
- T2
- T1ce
- FLAIR

虽然模态和你的 CT 任务不同，但这篇论文的价值在于：它提出了一种 **非常稳健的决策级融合思想**，特别适合样本不算很大、不同输入分支贡献不一样的场景。

### 3.2 深度学习模型方法

整体模型叫 `MMIDFNet`，由两部分组成：

1. 预训练肿瘤分割模块
2. 单模态分类 + 决策级融合模块

#### 第一步：肿瘤分割与 ROI 裁剪

作者先用 BraTS 2019 的预训练分割模型，得到：

- ET
- TC
- WT

最终选用 `WT`（whole tumor）作为 ROI，并将原始 MRI 按该区域中心裁剪为 `128 x 128 x 80`，然后做 max-min normalization。

这一步本质上和 C2 类似，也是 **先用结构/病灶 ROI 缩小问题空间**。

#### 第二步：单模态分类器训练

作者不是把四种 MRI 直接拼成一个大输入，而是给每个模态单独训练一个 3D 分类器。

单模态分类网络结构：

- 统一采用 `3D DenseNet-121`
- 四个 dense blocks
- 每个 dense block 的卷积层数分别为 `6 / 12 / 24 / 16`
- 使用 3D MRI volume 直接输入，不切成 2D slice
- 末端用两个全连接层映射到三类胶质瘤亚型

训练策略：

- focal loss 处理类别不平衡
- 初始学习率 `5e-4`
- Adam
- batch size `8`
- epoch `100`
- 使用 dropout、L2、weight decay、数据增强来抑制过拟合

数据增强包括：

- 尺寸缩放
- 随机旋转
- 随机缩放
- 高斯噪声
- 对比度调整

#### 第三步：决策级融合

这是论文最关键的部分。

作者没有把四模态特征在输入层或特征层拼接，而是在推理阶段，把四个预训练单模态模型输出的类别概率做 **线性加权和**：

`fusion_prob = Σ wi * probi`

其中：

- `probi` 是第 i 个模态模型输出的概率
- `wi` 是该模态的权重

权重不参与端到端训练，而是依据各单模态分类能力，通过启发式方式设定。

论文最后给出的模态权重为：

- T1ce：`2`
- FLAIR：`1`
- T2：`0.7`
- T1：`0.3`

### 3.3 网络结构创新

#### 创新点 1：不在输入层做数据级融合，而在输出层做决策级融合

这是这篇论文最值得关注的地方。

作者明确认为，多模态直接堆叠输入虽然方便，但有两个问题：

- 各模态贡献很难调节
- 模态之间的互补信息不一定能被网络自动学好

所以作者选择：

- 每个模态独立学习最适合自己的特征空间
- 最后再在决策层融合

这个思想迁移到足踝 CT 非常自然。你虽然没有 MRI 多模态，但可以把“模态”替换成：

- 轴位 / 冠状位 / 矢状位
- 骨窗 / 软组织窗
- 全局 ROI / 局部 lesion patch
- 原始体数据 / MIP / 厚层 slab

#### 创新点 2：让每个分支先成为“专家”，再做集成

这篇论文不是做一个大一统 backbone，而是做多个单模态专家模型，然后线性集成。

这种设计的优点是：

- 每个输入分支的统计分布不同也没关系
- 某个分支弱，不会拖垮全部特征学习
- 可以直接看到每个分支对最终预测的贡献

对于足踝 CT 二分类，临床上常见情况就是：

- 某些病例在冠状位更明显
- 某些病例在轴位更明显
- 某些病例在骨窗更明显

这种“专家分治 + 决策融合”特别稳。

#### 创新点 3：作者证明决策级融合优于 radiomics 和 data fusion

论文里三种多模态策略的平均表现分别是：

| 方法 | ACC | AUC | SEN | SPE | Kappa |
| --- | --- | --- | --- | --- | --- |
| Radiomics | `0.837` | `0.870` | `0.704` | `0.899` | `0.689` |
| Data fusion | `0.846` | `0.883` | `0.731` | `0.916` | `0.716` |
| Decision fusion（MMIDFNet） | `0.878` | `0.902` | `0.772` | `0.930` | `0.773` |

也就是说：

- 决策级融合比 data fusion 的 ACC 提高了 `3.2%`
- 也明显优于 radiomics pipeline

这说明在样本有限、模态贡献不同的医学任务里，**决策级融合非常可能比“直接拼输入”更稳、更容易调优**。

### 3.4 对你的足踝 CT 项目最有帮助的点

#### 可迁移点 A：把不同平面/窗口/尺度当成“伪模态”

你的 CT 虽然不是 MRI 多模态，但完全可以构造伪模态：

- Axial branch
- Coronal branch
- Sagittal branch
- Local zoom branch
- Bone window branch

每个 branch 用相同或相似 backbone 独立训练。

#### 可迁移点 B：先让每个 branch 单独跑到最好，再融合

这比一开始就做大一统 multi-input end-to-end 模型更稳，尤其适用于：

- 数据量不大
- 预处理方式还在探索
- 你还不确定哪一种视图最重要

你可以先单独比较每个 branch 的 AUC/F1，再决定融合权重。

#### 可迁移点 C：融合权重可以来源于验证集表现，而不是强行端到端学习

对于医学影像小样本任务，这是个很实用的工程策略。原因是：

- 参数更少
- 不容易过拟合
- 可解释性更好
- 容易迭代

### 3.5 我对它的迁移评价

优点：

- 风险最低
- 很适合小样本和多输入异质数据
- 可解释性好，便于做消融实验

局限：

- 它建模的是“决策层互补”，不是“特征层强交互”
- 如果你的任务非常依赖不同平面之间的精细对应关系，它可能不如 C1 那样强
- 权重启发式设置有时不是全局最优

结论：

- 这是 **最适合你先做 strong baseline 的方案**

## 三篇论文的横向对比

### 4.1 从“融合发生在哪一层”来看

| 论文 | 融合层级 | 融合对象 | 特点 |
| --- | --- | --- | --- |
| C1 XFMamba | 特征层，且分浅层与深层两级 | 多视图 feature maps | 强调跨视图交互与全局语义整合 |
| C2 FBA-CT | 输入表示层 + 病人级聚合层 | 结构先验后的多视角 snapshots | 强调 ROI 约束、多视角稳定聚合 |
| C3 MMIDFNet | 决策层 | 各分支输出概率 | 强调每个分支先独立学好，再做可解释融合 |

结论：

- 如果你要的是 **最强跨平面交互能力**，C1 最有启发
- 如果你要的是 **最高可落地性和稳健性**，C2 + C3 更适合

### 4.2 从“是否依赖结构先验”来看

| 论文 | 是否依赖 ROI/分割 | 作用方式 |
| --- | --- | --- |
| C1 | 不强依赖 | 主要靠多视图特征融合 |
| C2 | 强依赖 | 先气道分割，再做多视角分类 |
| C3 | 中等依赖 | 先肿瘤分割，再做 ROI 裁剪与分类 |

对你的任务，我更倾向于认为：

- 足踝 CT 二分类通常也应当引入 ROI/骨结构先验
- 因为原始 volume 背景冗余太大

### 4.3 从“小样本友好度”来看

| 论文 | 小样本友好度 | 原因 |
| --- | --- | --- |
| C1 | 中 | 模型更复杂，需要规范多视角设计 |
| C2 | 高 | 轻量 backbone + 结构先验 + 多视角聚合 |
| C3 | 很高 | 单分支独立训练 + 决策层融合，稳定性好 |

### 4.4 从“最适合足踝 CT 二分类”的角度排序

我的排序是：

1. `C2`
2. `C3`
3. `C1`

原因不是 C1 不好，而是：

- C1 更像高上限方案
- C2/C3 更像高成功率方案

## 对你的足踝 CT 二分类任务的具体启发

### 5.1 最建议直接借鉴的设计

#### 方案 A：C2 式 ROI 先验 + 多视角快照分类

推荐程度：`最高`

你可以这样做：

1. 对足踝 CT 做标准化重采样
2. 通过规则法、分割法或粗定位模型截取 ankle ROI
3. 生成多视角输入：
   - axial slab
   - coronal slab
   - sagittal slab
   - 可选 oblique / MIP / bone surface projection
4. 每个 view 输入轻量 CNN
5. 做 patient-level 概率聚合

适合原因：

- 训练稳定
- 易于解释
- 对小病灶更友好

#### 方案 B：C3 式多分支专家 + 决策级加权融合

推荐程度：`很高`

你可以把不同输入定义成伪模态：

- axial branch
- coronal branch
- sagittal branch
- local patch branch
- bone-window branch

每个 branch 独立训练，再按验证集表现加权融合。

这非常适合你在项目初期快速建立一个强 baseline。

#### 方案 C：C1 式跨平面 feature fusion

推荐程度：`中高`

当你已经验证：

- 多平面输入确实有效
- 数据规模允许
- baseline 已经稳定

再引入 C1 那种特征层 cross-fusion 会更合适。

### 5.2 我认为最值得你优先实验的创新点

#### 优先级 1：ROI/结构先验裁剪

来自：`C2 + C3`

理由：

- 这是最可能立刻提升 signal-to-noise ratio 的步骤
- 对医学 CT 二分类通常比换 backbone 更重要

#### 优先级 2：多视角病人级聚合

来自：`C2`

理由：

- 足踝异常常常不会在单一平面最清楚
- 多平面聚合比单切片分类更符合临床判读

#### 优先级 3：多分支加权决策融合

来自：`C3`

理由：

- 简单、稳、好调参
- 尤其适合样本量一般的场景

#### 优先级 4：跨视图特征交互模块

来自：`C1`

理由：

- 有潜力提升上限
- 但复杂度更高，建议放到第二阶段

### 5.3 不建议你直接照搬的部分

#### 不建议直接照搬 C2 的“3D 表面渲染”形式

原因：

- 气道树是天然的细长管状结构
- 足踝疾病不一定对应某个统一表面结构

更合理的改造是：

- 多平面 slab
- 多窗口
- 多尺度 patch

而不是机械地做表面快照。

#### 不建议一开始就直接上 C1 的 Mamba 大融合

原因：

- 你现在更需要的是稳定可复现的医学 baseline
- 如果数据量不够，复杂融合模型容易不稳定

## 给你的一个落地版模型建议

如果让我基于这三篇论文，为“足踝 CT 是否患病二分类”设计一个最实用的路线，我会这样组合：

### 第一阶段：先做强 baseline

参考 `C2 + C3`

- 预处理：重采样到统一 spacing
- ROI：粗定位足踝区域，尽量去掉无关背景
- 输入：
  - axial thick slab
  - coronal thick slab
  - sagittal thick slab
  - 可选 local lesion crop
- backbone：
  - 每个分支用 ResNet-18 / DenseNet-121 这类稳定 backbone
- 融合：
  - 先各分支独立训练
  - 再做验证集驱动的加权决策融合
- loss：
  - 若类别不平衡，优先试 focal loss

### 第二阶段：再做高上限增强

参考 `C1`

当第一阶段稳定后，再尝试：

- 在 axial/coronal/sagittal 分支倒数第二层插入 cross-view fusion block
- 先做浅层交互，再做深层融合
- 尝试“一个视图去重标定另一个视图的通道权重”

### 第三阶段：推荐补充的训练策略

参考 `C2`

- view dropout
- 病人级多视图概率平均/加权平均
- 数据增强时注意 plane 一致性
- 如果病灶偏小，优先关注 recall 和 F1，而不是只看 accuracy

## 最终结论

对你的项目而言，这三篇论文最重要的不是分别代表三种不同 backbone，而是代表三种不同的建模哲学：

1. `C1`：多视角之间要做强交互，不能只拼接
2. `C2`：先验结构约束和多视角表示，往往比重 backbone 更重要
3. `C3`：当不同输入分支贡献不一致时，决策级加权融合是非常稳健的工程方案

如果你的目标是尽快做出一个效果可靠、可解释、可扩展的足踝 CT 二分类模型，我建议优先顺序为：

1. `C2` 的 ROI/结构先验 + 多视角聚合
2. `C3` 的多分支专家 + 加权决策融合
3. `C1` 的跨视图特征融合增强

这套顺序最符合医学影像项目里“先稳、再强、最后再追上限”的路径。
